Deploy & PWA Setup Guide

Deploy for Free (3 Easy Methods):

Method 1: GitHub Pages (Recommended)

  1. Create a free account on GitHub.com.
  2. Create a new repository named meeting-tracker.
  3. Upload this index.html file directly to the repository.
  4. Go to Settings > Pages, select the main branch, and click Save.
  5. Your live HTTPS URL will be ready in 1 minute!

Method 2: Netlify Drop (No Account Needed)

  1. Go to app.netlify.com/drop.
  2. Put this index.html file inside a folder on your computer.
  3. Drag and drop the folder into Netlify Drop for instant hosting!

Method 3: Vercel CLI / Web

  1. Go to Vercel.com and log in.
  2. Import your GitHub repo containing this file for instant HTTPS deployment.

How to Install as PWA on Mobile / Desktop:

  • iOS (Safari): Tap the Share button > tap "Add to Home Screen".
  • Android (Chrome): Tap the 3 dots menu > tap "Install App" or "Add to Home screen".
  • Desktop (Chrome/Edge): Click the install icon in the URL bar.
